# java-calculator-precourse

## 기능 목록

### 1. 입출력

- [ ] 사용자의 입력을 camp.nextstep.edu.missionutils.Console의 readLine()으로 받기
- [ ] 입력 유효성 검증
- [ ] 덧셈 결과 출력

### 2. 문자열 파싱

- [ ] 기본 구분자(쉼표, 콜론)로 문자열의 숫자를 분리하기
- [ ] 커스텀 구분자 추가 기능

### 3. 숫자 추출 및 계산

- [ ] 추출한 문자열 형태의 숫자를 정수형으로 변환 후 덧셈 계산

### 4. 예외 처리

- 잘못된 입력값은 IllegalArgumentException 예외 발생 후 어플리케이션 종료
- 구조적 오류
  - [ ] 입력값이 null인 경우
  - [ ] 커스텀 구분자 선언 형식이 올바르지 않은 경우 ("\n"이 없거나 숫자 구분자인 경우)
- 내용적 오류
  - [ ] 구분자로 분리한 값 중에 숫자로 변환할 수 없는 문자가 있는 경우 (음수 기호를 포함)
  - [ ] 구분자 사이에 숫자가 없는 경우 (ex. "1,,2")
