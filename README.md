# java-calculator-precourse

## 기능 목록

### 1. 입출력

- [x] 사용자의 입력을 camp.nextstep.edu.missionutils.Console의 readLine()으로 받기
- [x] 덧셈 결과 출력

### 2. 문자열 처리

- [x] 커스텀 구분자 추가 기능
- [x] 구분자(쉼표, 콜론, 커스텀 구분자)로 문자열의 숫자를 분리하기
- [x] 추출한 문자열 형태의 숫자를 정수형으로 변환 후 덧셈 계산

### 3. 예외 처리

- 잘못된 입력값은 IllegalArgumentException 예외 발생 후 어플리케이션 종료
- 구조적 오류
  - [x] 입력값이 null인 경우
  - [x] 커스텀 구분자 선언, 형식이 올바르지 않은 경우 ("\n"이 없거나 숫자 구분자인 경우)
- 내용적 오류
  - [x] 구분자 사이에 숫자가 없는 경우 (ex. "1,,2")
  - [x] 입력값이 구분자로 끝나는 경우 (ex. "1,2,")
  - [x] 구분자로 분리한 값 중에 숫자로 변환할 수 없는 문자가 있는 경우
  - [ ] 구분자로 분리한 값 중에 음수가 있는 경우
